# Intentional conventions

The negative-rule ledger. Each row is a decision this repository made on
purpose. A reviewer, an advisor, or a CI check that flags one of these is
noise, not a finding. `egm-review` loads this file as context on every run.

| Convention | Why it is intentional |
| --- | --- |
| Skills carry exactly three frontmatter keys | A strict Agent Plugins consumer rejects any extension field. `disable-model-invocation` broke omp; ADR-0002. |
| `principle-*` descriptions start with `Apply when` | Principles are cited, not invoked. The validator enforces the form. |
| No shell scripts under `skills/` | Portability. Statechart runs through the Node launcher `run.mjs`. |
| Root `plugin.json` carries `$schema` | omp accepts it because skills carry no extension fields. |
| Embedded copies under `skills/*/references/` | Generated by `sync-assets` from `agents/` and `resources/`. Edit the canonical file only. |
| Generated regions between HTML markers | Machine-written by `build.mjs`. A hand edit fails `build --check`. |
| Rule packs are MIT condensations | They are not the books. NOTICE and per-file headers carry the license. |
| `ste100` paraphrases ASD-STE100 | The specification and dictionary are never vendored. ADR-0006. |
| `.egm/` is gitignored by default | Run artifacts are local. Promotion copies into `docs/designs/`. |
| Roster counts: 48 skills, 10 with the `egm-` prefix | Enforced by regression checks. A change updates the count, not the check. |
| Config comment lines `# reply-language:` and `# max-spawns-per-run:` | Parsed by skills at run time. They look like comments because hosts ignore them. |
| No per-harness persona copies | One canonical `agents/` tree. ADR-0003. |

A finding may challenge a convention only by arguing the decision itself, with
new evidence. Restating the convention as a defect is dropped without comment.
