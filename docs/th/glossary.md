# คำศัพท์

| คำ | ความหมาย |
| --- | --- |
| Elephant | agent ที่ถือ context โปรเจกต์และร่าง design |
| Goldfish | reviewer ที่เริ่มจาก context ว่าง |
| Stage | ขั้นของ review engine มี 5 ขั้น |
| Finding | ข้อค้นพบจาก reviewer |
| Severity | ระดับความรุนแรง: Blocker, Major, Nit |
| Disposition | วิธีจัดการ finding: CONTEST, ESCALATE, PROPOSE FIX, DECLINE |
| Clean round | รอบที่ไม่เหลือ Blocker หรือ Major ที่ยังเปิด |
| Convergence | สองรอบ clean ติดกัน |
| Loop | การวน review หลายรอบ สูงสุด 5 รอบ |
| Gate | คำถามเดียวที่หยุดรอผู้ใช้ |
| Artifact | ไฟล์ที่ skill เขียน เช่น brief, draft, report |
| Playbook | ลำดับขั้นสำหรับงานประเภทหนึ่ง |
| Principle | หลักการสั้น ๆ ที่อ้างอิงได้ |
| Rule pack | กฎจากหนังสือที่โหลดตามงาน |
| Profile | ชุด reviewer และช่วงเป้าหมายของ review |
| Preset | โหมดการรัน review เช่น interactive หรือ consolidated |
| Fresh context | reviewer ที่ไม่เห็นบทสนทนาก่อนหน้า |
| Drift | เอกสารกับโค้ดไม่ตรงกัน |
| Bounded context | ขอบเขตที่คำศัพท์หนึ่งมีความหมายเดียว |
| Aggregate | กลุ่ม object ที่รักษา invariant ด้วยกัน |
| Ubiquitous language | ภาษากลางที่ทีมและโค้ดใช้ตรงกัน |
| ADR | บันทึกการตัดสินใจทางสถาปัตยกรรม |
