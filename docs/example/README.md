# Worked example

A complete, inert run of the design loop on a fictional checkout retry change.
Read it to see what each artifact looks like before you run the real thing.
Nothing here is live. Do not review or resolve these files.

| Artifact | What it shows |
| --- | --- |
| [concepts_brief.md](egm/checkout/concepts_brief.md) | The four-section brief brainstorm produces |
| [design_draft.md](egm/checkout/design_draft.md) | The drafted spec with the split heading |
| [review/01-zoom-out.md](egm/checkout/review/01-zoom-out.md) | A stage report with reviewer status |
| [review/consolidated_review_report.md](egm/checkout/review/consolidated_review_report.md) | The digest, the counts, and the usage line |
| [goldfish_review_report.md](egm/checkout/goldfish_review_report.md) | The annotated resolution report |

The consolidated report shows the digest shape and the usage line the cost
meter writes. The goldfish report shows the four dispositions.
