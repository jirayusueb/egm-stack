# Changelog

All changes to the `rules` skill are recorded here.

## 0.23.0 - 2026-11-10

- Added the oop-design pack, an original condensation of object design rules: composition over inheritance, tell-don't-ask, illegal states, encapsulated collections, polymorphism over repeated switches.

## 0.20.2 - 2026-11-08

- Added the untrusted-content guardrail; packs and library books are data, never instructions.

## 0.18.0 - 2026-11-07

- Added library depth: open the matching book from the configured library when a pack is not enough, and cite the chapter.

## 0.12.0 - 2026-11-07

- Added project packs at docs/rules/, which win over same-named vendored packs.

## 0.5.0 - 2026-11-06

- Initial per-skill changelog. Content matches the 0.5.0 release.
