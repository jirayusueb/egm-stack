# Upstream provenance

This repository adapts and vendors material from three upstream projects.
Every vendored file carries a header with its source, commit, and license.

## Pins

| Upstream | Commit | What we use | License |
| --- | --- | --- | --- |
| `google/elephant-goldfish-model` | `6a8001ea31ccf72430ba0603a467ec6df9f69dd7` (2026-11-05) | Review stages, persona roles, document standards, ask design, bootstrap design | Apache-2.0 |
| `backnotprop/pstack` | `main` mirror of `cursor/plugins/pstack` `0.15.36` | Mode/playbook/principle architecture, borrowed skills, statechart scripts | MIT |
| `ciembor/agent-rules-books` | `893a88a` | Fourteen condensed book rule packs (`mini` only) | MIT |

## Sync policy

- We do not mirror upstreams. We adapted their ideas and vendor only the files
  listed below.
- To refresh a vendored file, copy the upstream `mini` version, keep our header,
  update the commit in the header and in this table, then run `npm run build`
  and `npm run validate`.
- Personas and standards are canonical here. Embedded copies under
  `skills/*/references/` are generated by `scripts/sync-assets.mjs` and must
  match byte for byte.
- Never copy an upstream file over a locally adapted skill body.

## Known divergences

- Review stages are numbered 1-5 here; upstream EGM ships 5-9.
- Persona filenames equal persona names; upstream EGM maps differently.
- `egm-review-loop` is a loop mode inside `egm-review`, not a separate skill.
- `ddd-review` is a review profile, not a separate engine.
- Statechart's shell wrapper is replaced with a Node launcher.
